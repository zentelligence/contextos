Journal

Where the Journal screen's date-partitioned entries live, and which Templater-compatible daily-note template a new day starts from: its sections become the day's tabs, in its order, and its first save writes it.

{% if let Some(error) = journal_error %}

{{ error }}

{% endif %}

A brand-new entry's own default path within the Journal directory, in Templater/moment.js format (YYYY, MM, DD, MMMM, dddd, Do, ww; / for real folders). This is only ever a default for a new entry, never a shape an existing one is assumed to fit.

A day's sections are the template's ## headings. The settings below name sections by their heading text, without the # marks; leave one blank for none.

A task is listed under these sections of the day's entry when it is created or closed. A day's entry without the section gains it.

One heading per line. These sections are shown but never offered for editing, such as one another tool appends to.
